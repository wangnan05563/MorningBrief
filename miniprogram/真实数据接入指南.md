# 真实数据接入指南（准确版）

## 系统架构理解

这个项目的节目**不是手动创建的**，而是通过以下自动化流程产生：

    爬虫抓取新闻 → LLM 生成稿件 → TTS 合成音频 → 人工审核 → 发布

所以后台管理系统中没有"节目管理 → 新建节目"菜单，节目是通过**工作流自动运行**产生的。

========================================
第一步：登录后台管理系统
========================================

1. 启动后端服务（确保运行在 8000 端口）
2. 打开浏览器访问：http://localhost:8000
3. 输入 admin 账号和密码登录
   - 首次登录密码在启动日志中查看（搜索 "initial admin password"）
   - 或在 backend\.env 中设置 ADMIN_INITIAL_PASSWORD

登录后你会看到左侧菜单：

    内容审核    ← 审核/发布节目（operator + admin）
    广告素材
    投放规则
    排期日历
    数据统计
    频道管理
    队列管理
    工作流监控  ← 触发节目自动生成（仅 admin）
    内网穿透
    AI 服务
    通知管理
    ...

========================================
第二步：触发节目自动生成
========================================

方法 A：等待定时任务自动运行
------------------------------
- 系统默认每天凌晨 5:00 自动运行工作流
- 无需手动操作

方法 B：手动触发立即生成
------------------------------
1. 登录后台 → 左侧菜单「工作流监控」
2. 点击右上角「手动触发」按钮
3. 等待工作流执行完成（几分钟）
4. 完成后会自动出现在「内容审核」列表中

========================================
第三步：审核并发布节目
========================================

1. 左侧菜单点击「内容审核」
2. 切换到「待审核」tab
3. 看到一条记录后，点击「审核」按钮
4. 进入审核详情页：
   - 左侧：查看稿件全文
   - 右侧：试听生成的音频
   - 操作区：选择「通过」或「打回」
5. 点击「通过」后，节目状态变为 published
6. 小程序就能通过 /api/v1/episodes/today 获取到这个节目

========================================
第四步：配置真实音频源
========================================

音频是由 TTS（文字转语音）自动生成的，需要配置后端 .env：

编辑 backend\.env：

    # 选择 TTS 方案（三选一）

    # 方案1：Edge-TTS（免费，推荐开发/小规模使用）
    TTS_PROVIDER=edge
    # 无需额外配置，开箱即用

    # 方案2：阿里云 TTS（付费，音质好）
    TTS_PROVIDER=aliyun
    ALIYUN_TTS_API_KEY=你的key
    ALIYUN_TTS_APPKEY=你的appkey

    # 方案3：腾讯云 TTS（付费，可复用 COS 凭证）
    TTS_PROVIDER=tencent
    TENCENT_TTS_SECRET_ID=你的secret_id
    TENCENT_TTS_SECRET_KEY=你的secret_key

音频生成后会：
- 如果配了 COS：上传到腾讯云 COS，返回 CDN 地址
- 如果没有配 COS：保存到 backend/data/audio_cache/，通过 /audio 目录访问

========================================
第五步：配置频道（可选）
========================================

1. 左侧菜单点击「频道管理」
2. 可以添加/编辑新闻频道（如：国际、科技、体育）
3. 每个频道可配置独立的：
   - 爬虫 URL（RSS 源或网页地址）
   - BGM 背景音乐
   - 播报风格

========================================
小程序端最终效果
========================================

配置完成后：

1. 小程序首页 → 显示今日节目（标题+日期+摘要）
2. 点击播放 → 播放 TTS 合成的音频
3. 点击「查看稿件」→ 跳转到详情页，展示完整文字
4. 历史页面 → 显示过往所有已发布的节目列表

========================================
常见问题
========================================

Q1：工作流触发后没有生成节目？
A1：检查「工作流监控」→ 点击工作流 ID 查看详情，看哪一步失败了
    通常是因为：爬虫 URL 不可达、LLM API 配置错误、TTS 凭证缺失

Q2：审核列表为空怎么办？
A2：先确认工作流已成功运行（状态为 success），如果工作流成功但审核列表仍为空，
    可能是 review 流程未启用，可直接通过数据库插入发布状态的节目：
    python add_test_episode.py

Q3：音频播放不了？
A3：检查 TTS_PROVIDER 配置是否正确，音频生成后会在日志中输出音频 URL，
    在浏览器中直接访问该 URL 测试是否能下载

Q4：如何跳过审核直接发布？
A4：可以在 backend\.env 中配置：
    WORKFLOW_AUTO_APPROVE=true
    这样工作流成功后自动发布，不进入审核流程

========================================
最简上手路径（5 步搞定）
========================================

1. 编辑 backend\.env，设置 TTS_PROVIDER=edge（免费，无需额外配置）
2. 启动后端服务
3. 浏览器打开 http://localhost:8000，登录 admin
4. 进入「工作流监控」→ 点击「手动触发」
5. 进入「内容审核」→ 点击审核 → 选择「通过」
6. 回到小程序 → 编译 → 首页即可看到节目！
