## 1. 引言

### 1.1 编写目的

本说明书在《概要设计说明书 V1.3》基础上，将架构与模块设计细化到可直接编码的程度。文档目标：

- 给出**可直接执行的 DDL 脚本**，包含字段类型、索引、外键、字符集；
- 给出**完整的 OpenAPI 接口定义**，可直接导入 Swagger/Postman；
- 给出**模块级伪代码**，明确类/函数签名、调用关系、关键分支；
- 给出**关键算法实现**（SimHash、热度公式、敏感词过滤、重试策略）；
- 给出**可复制的配置文件与部署文件**（YAML、Dockerfile、Nginx、PowerShell 脚本）。

读者读完后应能够：直接搭建开发环境、按章节实现对应模块、无需再向架构师确认细节即可编码。

### 1.2 项目背景

详见《需求规格说明书》第 1.2 节与《概要设计说明书》第 1.2 节。本项目核心是一套**全自动 AI 内容生产工作流**：每日凌晨爬取前一日全网资讯 → LLM 改写为可播报稿 → 云端 TTS API 语音合成 → FFmpeg 拼接三段式广告 → 人工审核后 07:00 发布到微信小程序。系统采用**单机部署 + 单体应用**架构（FastAPI + APScheduler + 内部模块函数调用），4 个 Docker 容器（nginx/app/mysql/redis），11 张 MySQL 表。

#### 1.4.4 接口响应规范

所有 HTTP 接口统一响应格式（继承 HLD 6.1）：

```json
{
  "code": 0,
  "message": "ok",
  "data": { ... }
}
```

错误响应：

```json
{
  "code": 40001,
  "message": "参数错误：date 不能为空",
  "data": null
}
```

`code = 0` 表示成功；非 0 表示错误，错误码定义见 LLD 13.1。

#### 1.4.5 时间与时区约定

- 数据库时间字段统一 `DATETIME`，存储 UTC 时间，应用层显示时按 `Asia/Shanghai` 转换；
- APScheduler Cron 表达式按 `Asia/Shanghai` 时区配置（如 `05:00` 触发即北京时间凌晨 5 点）；
- API 入参/出参时间字段统一 ISO 8601 字符串（如 `2026-07-07T05:00:00+08:00`）。

## 2. 完整 DDL 脚本

> 本章给出 11 张表的完整 DDL，可直接在 MySQL 8.0 执行。字符集统一 `utf8mb4`，存储引擎统一 `InnoDB`。所有外键 `ON DELETE RESTRICT ON UPDATE CASCADE`，避免误删导致脏数据。

### 2.1 数据库与用户创建

```sql
-- 创建数据库（首次部署执行）
CREATE DATABASE IF NOT EXISTS `news_db`
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

USE `news_db`;

-- 创建应用账号（生产环境禁用 root）
CREATE USER IF NOT EXISTS 'news_app'@'%' IDENTIFIED BY 'CHANGE_ME_IN_PROD';
GRANT SELECT, INSERT, UPDATE, DELETE ON `news_db`.* TO 'news_app'@'%';
FLUSH PRIVILEGES;
```

### 2.2 表创建顺序

按外键依赖拓扑排序，避免创建失败：

```
user → admin_user → ad_material → material → script → workflow
                                                                ↓
                                                              review → episode → play_log
                                                                          ↑
                                                              ad_placement（依赖 ad_material）
                                                              workflow_step（依赖 workflow）
```

## 3. Redis 数据结构详细设计

> 本章给出 Redis 键命名规范、数据类型、TTL 策略与操作示例，可直接指导编码。Redis 仅用于缓存与高频读写场景，**不持久化业务数据**——所有业务数据以 MySQL 为准。

### 3.1 键命名规范

**统一格式**：`{namespace}:{subnamespace}:{id}[:{sub_id}]`

- 全小写，冒号分隔；
- namespace 表示业务域（episode/playlog/workflow/crawler/ad/rate_limit/user）；
- 变长 ID 用具体值替换；
- 避免特殊字符与空格。

### 3.2 键清单总览

| Key 模式 | 类型 | 用途 | TTL | 写入方 | 读取方 |
| --- | --- | --- | --- | --- | --- |
| `episode:today` | String(JSON) | 今日节目元数据缓存 | 1 小时 | 内容服务 | C 端 episodes 接口 |
| `episode:list:page:{n}` | String(JSON) | 历史列表分页缓存 | 10 分钟 | 内容服务 | C 端 episodes 接口 |
| `episode:detail:{id}` | String(JSON) | 节目详情缓存 | 30 分钟 | 内容服务 | C 端 episodes 接口 |
| `script:detail:{id}` | String(JSON) | 稿件详情缓存（懒加载） | 30 分钟 | 内容服务 | C 端 episodes/script 接口 |
| `playlog:progress:{user_id}:{episode_id}` | Hash | 实时播放进度 | 永久（仅手动清理） | C 端 play 接口 | C 端 play 接口 |
| `playlog:flush:queue` | List | 待落库播放日志队列 | 无（消费后删除） | C 端 play 接口 | 异步消费者 → play_log |
| `workflow:current` | String | 当前运行中工作流 ID | 工作流结束清除 | 工作流调度服务 | 工作流调度服务 |
| `workflow:lock` | String + NX | 工作流触发互斥锁 | 30 分钟 | 工作流调度服务 | 工作流调度服务 |
| `crawler:dedup:url` | Set | URL 去重（7 天滑动窗口） | 7 天 | 爬虫模块 | 爬虫模块 |
| `crawler:dedup:simhash:{category}` | Set | SimHash 指纹按品类去重 | 7 天 | 爬虫模块 | 爬虫模块 |
| `ad:placement:{date}` | Hash | 当日广告投放缓存 | 25 小时 | 广告服务 | 拼接模块、广告服务 |
| `rate_limit:api:{user_ip}` | String(INCR) | 接口限流计数 | 1 分钟 | FastAPI 中间件 | FastAPI 中间件 |
| `user:session:bl:{jti}` | String(1) | C 端 JWT 登出黑名单 | JWT 剩余有效期 | 用户服务 | deps.py 鉴权中间件 |
| `admin:session:bl:{jti}` | String(1) | B 端 JWT 登出黑名单 | JWT 剩余有效期 | 审核服务 | deps.py 鉴权中间件 |
| `stats:daurset:{yyyymmdd}` | Bitmap | DAU 用户位图 | 90 天 | C 端 play 接口 | 统计服务 |

### 3.3 详细设计

#### 3.3.1 `episode:today` — 今日节目缓存

```redis
# 写入（内容服务发布后立即刷新）
SET episode:today '{"id":123,"date":"2026-07-07","title":"7月7日 · 今日要闻","duration":600,"audio_url":"https://cdn.../ep123.mp3","cover_url":"..."}'
EXPIRE episode:today 3600

# 读取（C 端 /api/v1/episodes/today）
GET episode:today
# 缓存未命中 → 查 MySQL episode 表 WHERE date=CURDATE() AND status='published' → 回写缓存
```

**缓存策略**：cache-aside；发布时主动 `DEL episode:today` 触发下次读重建。

#### 3.3.2 `playlog:progress:{user_id}:{episode_id}` — 播放进度

```redis
# 写入（每 10 秒上报一次）
HSET playlog:progress:100:123 position 180 duration 180 completed 0 updated_at 1720310400

# 读取（用户回到节目时拉取进度）
HGETALL playlog:progress:100:123
# 返回 {position:180, duration:180, completed:0, updated_at:1720310400}

# 完播时标记
HSET playlog:progress:100:123 completed 1 position 600 duration 600
```

**为什么用 Hash 不用 String**：进度是 4 字段的复合结构，Hash 支持单字段更新（仅 position），避免每次序列化整个对象。**为什么不设 TTL**：用户可能数周后回来继续听，永久保留进度；如需清理可对 30 天未更新进度做后台扫描。

#### 3.3.3 `playlog:flush:queue` — 播放日志异步落库队列

```redis
# 生产端（C 端 play 接口，每次进度上报）
LPUSH playlog:flush:queue '{"user_id":100,"episode_id":123,"session_id":"s-xxx","position":180,"duration":180,"completed":0,"played_at":"2026-07-07T05:00:00"}'

# 消费端（APScheduler 每 1 分钟触发）
# 1. 批量取出（不阻塞）
LRANGE playlog:flush:queue 0 499        # 取前 500 条
# 2. 解析后批量 INSERT play_log 表
# 3. 删除已处理条目
LTRIM playlog:flush:queue 500 -1
```

**为什么用 List 不用 Stream**：MVP 无需消费者组与 ACK 机制，List + LTRIM 简单可靠；如需更可靠投递二期可换 Stream。

#### 3.3.4 `crawler:dedup:url` — URL 去重

```redis
# 爬虫拉取新 URL 后检查
SISMEMBER crawler:dedup:url "https://example.com/news/123"
# 返回 0 → 新 URL，加入集合
SADD crawler:dedup:url "https://example.com/news/123"
# 设置 7 天 TTL（首次 SADD 时执行，7 天后自动清理）
EXPIRE crawler:dedup:url 604800
```

**为什么用 Set 不用 Bloom Filter**：MVP 单日 URL 量 50-100，7 天累积 < 1000，Set 内存占用可忽略；Bloom Filter 有假阳性，去重场景要求精确，Set 更合适。

#### 3.3.5 `crawler:dedup:simhash:{category}` — 标题 SimHash 去重

```redis
# 按品类分桶（避免跨品类误判）
SADD crawler:dedup:simhash:科技 "ab3f2c9e1d8a"  # 新素材 SimHash 指纹
EXPIRE crawler:dedup:simhash:科技 604800

# 检查时遍历品类集合，对每个已有指纹计算汉明距离
SMEMBERS crawler:dedup:simhash:科技
# 应用层计算汉明距离 ≤ 3 视为近似重复
```

**为什么按品类分桶**：跨品类标题可能恰好相似（如"重大突破"），不应判重；分桶减少比较次数。

#### 3.3.6 `ad:placement:{date}` — 当日广告投放缓存

```redis
# 写入（广告服务每日 00:00 预加载）
HSET ad:placement:2026-07-07 head '{"material_id":1,"file_url":"...","duration":5}'
HSET ad:placement:2026-07-07 mid  '{"material_id":2,"file_url":"...","duration":30}'
HSET ad:placement:2026-07-07 tail '{"material_id":3,"file_url":"...","duration":10}'
EXPIRE ad:placement:2026-07-07 90000  # 25 小时（跨过次日 00:00 后失效）

# 读取（拼接模块 05:23 取用）
HGETALL ad:placement:2026-07-07
```

**TTL 25 小时而非 24 小时**：避免缓存刚好在 05:00 工作流执行前失效导致查询压力，多 1 小时缓冲。

#### 3.3.7 `workflow:lock` — 工作流互斥锁

```redis
# 触发工作流前抢锁（SET NX 是原子的）
SET workflow:lock "wf-20260707-0001" NX EX 1800
# 返回 OK → 获取锁成功，开始工作流
# 返回 nil → 已有工作流在运行，拒绝重复触发

# 工作流结束（无论成功失败）主动释放
DEL workflow:lock
```

**为什么需要互斥锁**：APScheduler 可能因网络抖动重复触发，运营也可能在 05:00 误点手动触发；锁保证同一时刻只有一个工作流运行。

#### 3.3.8 `rate_limit:api:{user_ip}` — 接口限流

```redis
# FastAPI 中间件，每次请求
INCR rate_limit:api:192.168.1.100
# 首次 INCR 后设置 TTL
EXPIRE rate_limit:api:192.168.1.100 60  # 1 分钟滑动窗口
# 计数 > 60 → 返回 429
```

**限流策略**：单 IP 每分钟 60 次，超限返回 429；运营后台 IP 白名单可豁免。

#### 3.3.9 `user:session:bl:{jti}` / `admin:session:bl:{jti}` — JWT 登出黑名单

```redis
# 登出时写入黑名单（jti 是 JWT 的唯一标识，在 token 签发时生成）
SET user:session:bl:abc123def456 "1"
EXPIRE user:session:bl:abc123def456 518400  # JWT 剩余有效期（7天 - 已用时间）

# 中间件校验流程
# 1. 本地 JWT 验签（无需查 Redis，性能优）
# 2. 查黑名单：jti 是否命中
GET user:session:bl:abc123def456
# 命中 → 401（已登出）；未命中 → 注入 request.state.user

# 强制下线（运营后台操作）
SET admin:session:bl:xyz789 "1"
EXPIRE admin:session:bl:xyz789 7200  # 剩余有效期
```

**为什么用 JWT + 黑名单而不是 Redis 全量会话**：JWT 本地验签性能优（O(1) 本地操作），仅登出/强制下线时写 Redis 黑名单。避免"JWT + 全量 session 双写"的双重真相反模式——既保留 JWT 无状态优势，又支持主动失效。黑名单 QPS 极低（仅登出时写），对 Redis 压力可忽略。

#### 3.3.10 `stats:daurset:{yyyymmdd}` — DAU 位图

```redis
# C 端 play 接口，用户访问时设置位
SETBIT stats:daurset:20260707 100 1   # user_id=100 当日活跃
EXPIRE stats:daurset:20260707 7776000  # 90 天

# 统计服务查询 DAU
BITCOUNT stats:daurset:20260707       # 返回当日活跃用户数
# 多日 DAU 计算（如周活跃）
BITOP OR stats:temp:weekly stats:daurset:20260701 stats:daurset:20260702 ...
BITCOUNT stats:temp:weekly
DEL stats:temp:weekly                  # 用完即删
```

**为什么用 Bitmap 不用 Set**：user_id 是数字，Bitmap 内存占用极低（100 万用户约 125 KB）；BITOP 多日合并高效。

### 3.5 缓存失效策略

| 场景 | 策略 | 实现 |
| --- | --- | --- |
| 节目发布 | 主动失效 | `DEL episode:today episode:detail:{id} episode:list:page:*` |
| 稿件审核通过 | 主动失效 | `DEL script:detail:{id}` |
| 广告投放修改 | 主动失效 | `DEL ad:placement:{today}` |
| 工作流重新触发 | 主动失效 | `DEL episode:today episode:list:page:*` |
| 缓存命中过期 | 被动失效 | TTL 到期自动清除 |
| 缓存数据错误 | 紧急失效 | 运营后台提供"刷新缓存"接口，按 key 模式批量删除 |

**通配符删除注意**：Redis 不支持原子通配符删除，需先 `KEYS` 后逐个 `DEL`，生产环境改用 `SCAN` 避免阻塞。

#### 5.1.2 工作流执行伪代码

```python
async def _run_workflow(self, workflow_id: str, episode_date: date) -> None:
    """工作流主流程：6 步串行执行"""
    # 步骤定义（顺序、对应模块函数）
    STEPS = [
        ("crawl",   1, crawler.run),
        ("rewrite", 2, llm.rewrite),
        ("tts",     3, tts.synthesize),
        ("stitch",  4, stitch.concat),
        ("review",  5, self._create_review),       # 内置：创建 review 记录
        ("publish", 6, self.publish),               # 仅审核通过后执行
    ]

    try:
        # 抢 Redis 互斥锁，防止并发触发
        lock_ok = await self.redis.set(
            "workflow:lock", workflow_id, nx=True, ex=1800
        )
        if not lock_ok:
            raise WorkflowConflictError("已有工作流在运行")

        await self.redis.set("workflow:current", workflow_id)
        await self._update_workflow_status(workflow_id, "running")

        context = {"workflow_id": workflow_id, "episode_date": episode_date}

        # 前 4 步：crawl → rewrite → tts → stitch
        for step_name, seq, func in STEPS[:4]:
            await self._run_step(workflow_id, step_name, seq, func, context)

        # 第 5 步：创建审核记录（内部方法，不调用外部模块）
        await self._run_step(workflow_id, "review", 5, self._create_review, context)

        # 第 6 步 publish 由审核通过后异步触发，不在主流程内串行执行
        # 主流程到 review 创建即结束，状态置 success
        await self._update_workflow_status(workflow_id, "success")

    except StepFailedError as e:
        # 某步重试耗尽仍失败
        await self._update_workflow_status(workflow_id, "failed", error=str(e))
        await self._alert_operators(f"工作流 {workflow_id} 失败于步骤 {e.step_name}: {e}")
        # 不立即启用备播，等到 06:30 由 _check_backup 统一处理
    finally:
        await self.redis.delete("workflow:lock")
        await self.redis.delete("workflow:current")


async def _run_step(self, workflow_id, step_name, seq, func, context):
    """执行单步：记录状态、调用函数、失败重试 3 次"""
    step_record = await self._create_step_record(workflow_id, step_name, seq)
    await self._update_step_status(step_record.id, "running")

    last_error = None
    for attempt in range(3):  # 最多 3 次（含首次）
        try:
            result = await func(context)            # 调用工作流模块函数
            await self._update_step_status(
                step_record.id, "success",
                result=result, retry_count=attempt,
                duration_ms=int((time.time() - step_record.started_at.timestamp()) * 1000)
            )
            context.update(result or {})            # 将本步产出合并到上下文供后续步骤使用
            return
        except Exception as e:
            last_error = e
            await self._update_step_status(step_record.id, "retrying", retry_count=attempt + 1)
            if attempt < 2:
                await asyncio.sleep(5 * (attempt + 1))   # 指数退避 5s/10s

    # 3 次均失败
    await self._update_step_status(step_record.id, "failed", error=str(last_error))
    raise StepFailedError(step_name, last_error)
```

```python
async def _check_backup(self) -> None:
    """06:30 检查今日 episode 是否已发布；未发布则启用备播"""
    today = date.today()
    episode = await self.db.execute(
        select(Episode).where(Episode.date == today, Episode.status == "published")
    )
    if episode:
        return  # 已正常发布，无需备播

    # 查询前一日已发布节目
    yesterday = today - timedelta(days=1)
    prev = await self.db.execute(
        select(Episode).where(Episode.date == yesterday, Episode.status == "published")
    )
    if not prev:
        await self._alert_operators("前一日节目也不存在，无法备播！需人工介入")
        return

    # 创建备播 episode
    backup = Episode(
        date=today,
        title=f"{today.month}月{today.day}日 · 今日要闻（备播）",
        duration=prev.duration,
        audio_url=prev.audio_url,                    # 复用前一日音频
        cover_url=prev.cover_url,
        is_backup=True,
        status="published",
        published_at=datetime.now(),
    )
    self.db.add(backup)
    await self.db.commit()

    # 刷新缓存
    await self.redis.delete("episode:today")
    await self._alert_operators(f"已启用备播（复用 {yesterday} 节目音频），请事后排查原因")
```

```python
async def run(context: dict) -> dict:
    workflow_id = context["workflow_id"]
    sources = _load_sources()                       # 从 rss.yaml + lists.yaml 加载配置
    all_materials = []

    # 并发爬取所有源（每源独立容错，单源失败不影响其他源）
    tasks = [_crawl_one_source(src, workflow_id) for src in sources]
    results = await asyncio.gather(*tasks, return_exceptions=True)

    for src, result in zip(sources, results):
        if isinstance(result, Exception):
            logger.warning(f"源 {src['name']} 爬取失败: {result}")
            continue
        all_materials.extend(result)

    # 去重（URL + SimHash）
    deduped = await _dedup(all_materials, workflow_id)

    # 落库
    await _save_to_mysql(deduped)

    return {"material_count": len(deduped), "materials": deduped[:5]}  # 上下文只传前 5 条预览


async def _crawl_one_source(src: dict, workflow_id: str) -> list[dict]:
    """爬取单个源"""
    if src["type"] == "rss":
        return await rss_spider.crawl(src, workflow_id)
    elif src["type"] == "list":
        return await list_spider.crawl(src, workflow_id)
    else:
        raise ValueError(f"未知源类型: {src['type']}")


async def _dedup(materials: list[dict], workflow_id: str) -> list[dict]:
    """URL 去重 + SimHash 近似去重"""
    result = []
    for m in materials:
        # URL 去重（Redis Set）
        if await redis.sismember("crawler:dedup:url", m["url"]):
            continue
        # SimHash 计算 + 近似去重
        m["simhash"] = simhash.compute(m["title"])
        is_dup = False
        existing_hashes = await redis.smembers(f"crawler:dedup:simhash:{m['category']}")
        for h in existing_hashes:
            if simhash.hamming_distance(m["simhash"], h) <= 3:
                is_dup = True
                break
        if is_dup:
            continue

        # 标记已处理
        await redis.sadd("crawler:dedup:url", m["url"])
        await redis.sadd(f"crawler:dedup:simhash:{m['category']}", m["simhash"])
        result.append(m)

    return result


async def _save_to_mysql(materials: list[dict]) -> None:
    """批量插入 material 表（ON DUPLICATE KEY UPDATE 容错）"""
    async with db_session.begin():
        await db_session.execute(
            insert(Material),
            materials,
        )
```

```python
async def call_llm(prompt: str) -> str:

async def rewrite(context: dict) -> dict:
    workflow_id = context["workflow_id"]
    episode_date = context["episode_date"]

    # 1. 拉取当日全部素材
    materials = await _fetch_materials(episode_date)

    # 2. 选题：按品类分组，每品类选 1-2 篇热度最高
    selected = _select_top_materials(materials, top_n=6)

    # 3. 并发改写（5-6 条同时调用 LLM）
    tasks = [_rewrite_one(m) for m in selected]
    results = await asyncio.gather(*tasks, return_exceptions=True)

    # 4. 过滤失败项 + 敏感词扫描
    segments = []
    for m, r in zip(selected, results):
        if isinstance(r, Exception):
            logger.warning(f"素材 {m['id']} 改写失败: {r}")
            continue
        if sensitive_filter.contains(r["content"]):
            # 命中敏感词，重新生成一次（带约束 prompt）
            r = await _rewrite_one(m, retry_with_constraint=True)
        segments.append({**r, "seq": len(segments) + 1, "material_ids": [m["id"]]})

    if len(segments) < 3:
        raise LLMError(f"有效改写段数 {len(segments)} < 3，无法生成节目")

    # 5. 组装整稿（开场白 + 改写段 + 结尾）
    full_text, segments_with_intro = _assemble_script(segments, episode_date)

    # 6. 时长估算（210 字/分钟）
    total_words = sum(len(s["content"]) for s in segments_with_intro)
    estimated_duration = int(total_words / 210 * 60)

    # 7. 落库 script 表
    script = await _save_script(
        workflow_id=workflow_id,
        episode_date=episode_date,
        full_text=full_text,
        segments=segments_with_intro,
        total_words=total_words,
        estimated_duration=estimated_duration,
        referenced_materials=[{"title": m["title"], "url": m["url"]} for m in selected],
        categories=list({m["category"] for m in selected}),
    )

    return {"script_id": script.id, "segments": segments_with_intro, "estimated_duration": estimated_duration}


def _select_top_materials(materials: list[dict], top_n: int = 6) -> list[dict]:
    """按品类分组，每品类选 1-2 篇热度最高

    热度 = 源权威度 × 0.3 + 标题关键词热度 × 0.4 + 发布时间近度 × 0.3
    """
    by_category = defaultdict(list)
    for m in materials:
        by_category[m["category"]].append(m)

    selected = []
    for cat, items in by_category.items():
        items.sort(key=lambda m: _heat_score(m), reverse=True)
        selected.extend(items[:2])                  # 每品类最多 2 篇
        if len(selected) >= top_n:
            break
    return selected[:top_n]


def _heat_score(material: dict) -> float:
    """热度计算：源权威度 30% + 标题关键词热度 40% + 发布时间近度 30%"""
    authority = material["source_authority"]                    # 0-1
    keyword_heat = _keyword_heat(material["title"])            # 0-1
    recency = _recency_score(material["published_at"])         # 0-1，越近越高
    return authority * 0.3 + keyword_heat * 0.4 + recency * 0.3
```

```python
async def synthesize(context: dict) -> dict:
    segments = context["segments"]

    # 并发合成所有分段（云端 API 无本地显存限制）
    tasks = [synthesize_segment(seg["content"]) for seg in segments]
    raw_audios = await asyncio.gather(*tasks, return_exceptions=True)

    audio_segments = []
    for seg, raw in zip(segments, raw_audios):
        if isinstance(raw, Exception):
            logger.warning(f"段 {seg['seq']} 合成失败: {raw}")
            continue

        # 后处理：响度归一化（-16 LUFS 播客标准）+ 去静音
        processed = normalize_loudness(raw, target_lufs=-16)
        processed = trim_silence(processed, threshold_db=-50)

        # 上传 COS
        url = await upload_to_cos(
            processed,
            key=f"tts/{context['workflow_id']}/seg_{seg['seq']}.mp3",
        )
        duration = _get_audio_duration(processed)
        audio_segments.append({
            "seg_seq": seg["seq"],
            "audio_url": url,
            "duration": duration,
        })

    if len(audio_segments) < len(segments) * 0.5:
        raise TTSError(f"合成成功段数 {len(audio_segments)} < 总段数 {len(segments)} 的 50%")

    return {"audio_segments": audio_segments}
```

```python
async def concat(context: dict) -> dict:
    workflow_id = context["workflow_id"]
    episode_date = context["episode_date"]

    ad_head_url = placements.get("head", {}).get("file_url") or "/ads/default_5s.mp3"
    ad_mid_url = placements.get("mid", {}).get("file_url") or "/ads/default_30s.mp3"
    ad_tail_url = placements.get("tail", {}).get("file_url") or "/ads/default_10s.mp3"

    # 4. 中间广告插入（在 300s 处切开）
    main_with_mid = "/tmp/{workflow_id}/main_with_mid.mp3"
    await run_ffmpeg(_build_mid_ad_cmd(main_mp3, ad_mid_url, main_with_mid, insert_at=300))

    # 5. 开头与结尾广告拼接（含 0.5s 静音过渡）
    final_mp3 = "/tmp/{workflow_id}/final.mp3"
    await run_ffmpeg(_build_full_concat_cmd(
        silence_05s, ad_head_url, silence_05s,
        main_with_mid,
        silence_05s, ad_tail_url, silence_05s,
        final_mp3,
    ))

    # 6. 时长校验（9:30-10:30 之间）
    duration = _get_audio_duration(final_mp3)
    if not 570 <= duration <= 630:
        raise StitchError(f"拼接后时长 {duration}s 超出 9:30-10:30 范围")

    # 7. 上传 COS
    final_url = await upload_to_cos(
        open(final_mp3, "rb").read(),
        key=f"episodes/{episode_date.strftime('%Y%m%d')}/final.mp3",
    )

    return {"final_audio_url": final_url, "duration": duration}


def _build_full_concat_cmd(*inputs, output) -> list[str]:
    """构造 7 段拼接的 FFmpeg 命令：静音+广告+静音+主音频+静音+广告+静音"""
    cmd = ["ffmpeg"]
    for path in inputs[:-1]:
        cmd.extend(["-i", path])
    cmd.extend([
        "-filter_complex", "concat=n=7:v=0:a=1[out]",
        "-map", "[out]",
        "-acodec", "libmp3lame",
        "-b:a", "128k",
        "-ar", "44100",
        "-ac", "1",                            # 单声道
        output,
    ])
    return cmd
```

```python
class UserService:
    def __init__(self, db: AsyncSession, redis: Redis):
        self.db = db
        self.redis = redis

    async def login_by_code(self, code: str) -> dict:
        """微信小程序登录

        流程：
        1. 用 code 调微信 code2session 换 openid
        2. 查 user 表，不存在则新建（首次登录自动注册）
        3. 生成 JWT（含 jti、user_id、openid、exp），本地签发不写 Redis
        4. 返回 token + 用户基本信息
        """
        # 1. 换 openid
        wx_resp = await self._call_wx_code2session(code)
        openid = wx_resp["openid"]
        unionid = wx_resp.get("unionid")

        # 2. 查或建用户
        user = await self.db.execute(
            select(User).where(User.openid == openid)
        )
        user = user.scalar_one_or_none()
        if user is None:
            user = User(openid=openid, unionid=unionid, created_at=datetime.utcnow())
            self.db.add(user)
            await self.db.commit()
            await self.db.refresh(user)

        # 3. 更新最近活跃时间
        user.last_active_at = datetime.utcnow()
        await self.db.commit()

        # 4. 生成 JWT（无状态，不写 Redis；jti 用于登出黑名单）
        import jwt as pyjwt
        import uuid
        jti = uuid.uuid4().hex
        payload = {
            "jti": jti,
            "user_id": user.id,
            "openid": user.openid,
            "nickname": user.nickname,
            "exp": int((datetime.utcnow() + timedelta(days=7)).timestamp()),
            "iat": int(datetime.utcnow().timestamp()),
        }
        token = pyjwt.encode(payload, settings.JWT_SECRET, algorithm="HS256")

        return {
            "token": token,
            "expires_in": 7 * 86400,
            "user": {
                "openid": user.openid,
                "nickname": user.nickname,
                "avatar": user.avatar,
            },
        }

    async def logout(self, token: str) -> None:
        """退出登录：将 jti 写入 Redis 黑名单（TTL=JWT 剩余有效期）"""
        import jwt as pyjwt
        try:
            payload = pyjwt.decode(token, settings.JWT_SECRET, algorithms=["HS256"])
        except pyjwt.PyJWTError:
            return  # token 已过期或无效，无需写黑名单
        jti = payload["jti"]
        exp = payload["exp"]
        remaining_ttl = exp - int(datetime.utcnow().timestamp())
        if remaining_ttl > 0:
            await self.redis.set(f"user:session:bl:{jti}", "1", ex=remaining_ttl)

    async def get_user_by_token(self, token: str) -> dict | None:
        """中间件鉴权用：JWT 本地验签 + 查黑名单"""
        import jwt as pyjwt
        try:
            payload = pyjwt.decode(token, settings.JWT_SECRET, algorithms=["HS256"])
        except pyjwt.PyJWTError:
            return None  # 验签失败或已过期
        # 查黑名单（仅登出的 token 才会命中）
        if await self.redis.exists(f"user:session:bl:{payload['jti']}"):
            return None  # 已登出
        return {
            "user_id": payload["user_id"],
            "openid": payload["openid"],
            "nickname": payload.get("nickname"),
        }
```

```python
class PlayService:
    """播放进度上报与查询；DAU 记录"""

    async def report_progress(
        self, user_id: int, episode_id: int,
        position: int, duration: int, completed: bool, session_id: str,
    ) -> None:
        """上报播放进度

        1. 写 Redis Hash playlog:progress:{user_id}:{episode_id}
        2. LPUSH playlog:flush:queue（异步消费到 play_log 表）
        3. SETBIT stats:daurset:{yyyymmdd} {user_id} 1（记录 DAU）
        4. 若首次完播，INCR episode.complete_count
        """
        # 1. 实时进度写 Redis Hash
        progress_key = f"playlog:progress:{user_id}:{episode_id}"
        await self.redis.hset(progress_key, mapping={
            "position": position,
            "duration": duration,
            "completed": int(completed),
            "updated_at": int(time.time()),
        })

        # 2. 日志入队列
        log_entry = json.dumps({
            "user_id": user_id,
            "episode_id": episode_id,
            "session_id": session_id,
            "position": position,
            "duration": duration,
            "completed": int(completed),
            "played_at": datetime.utcnow().isoformat(),
        }, ensure_ascii=False)
        await self.redis.lpush("playlog:flush:queue", log_entry)

        # 3. DAU 位图
        today_key = f"stats:daurset:{date.today().strftime('%Y%m%d')}"
        await self.redis.setbit(today_key, user_id, 1)
        await self.redis.expire(today_key, 90 * 86400)

        # 4. 完播计数（首次完播才累加，避免重复）
        if completed and not await self.redis.hget(progress_key, "completed_recorded"):
            await self.db.execute(
                update(Episode)
                .where(Episode.id == episode_id)
                .values(complete_count=Episode.complete_count + 1)
            )
            await self.db.commit()
            await self.redis.hset(progress_key, "completed_recorded", 1)

    async def get_progress(self, user_id: int, episode_id: int) -> dict | None:
        """获取上次播放进度（断点续播）"""
        data = await self.redis.hgetall(f"playlog:progress:{user_id}:{episode_id}")
        if not data:
            return None
        return {
            "episode_id": episode_id,
            "position": int(data.get("position", 0)),
            "completed": bool(int(data.get("completed", 0))),
            "updated_at": datetime.fromtimestamp(int(data["updated_at"])).isoformat(),
        }

    async def flush_playlog_queue(self) -> int:
        """APScheduler 每 1 分钟调用：批量落库 play_log

        1. LRANGE 取前 500 条
        2. 批量 INSERT play_log 表
        3. LTRIM 删除已处理条目
        返回：本批次处理条数
        """
        items = await self.redis.lrange("playlog:flush:queue", 0, 499)
        if not items:
            return 0

        rows = [json.loads(item) for item in items]
        # session_id 不变 + position 不变视为同一次上报，可去重
        # 简化处理：直接批量插入，依赖 play_log 索引
        await self.db.execute(insert(PlayLog), rows)
        await self.db.commit()

        await self.redis.ltrim("playlog:flush:queue", 500, -1)
        return len(rows)
```

```python
class StatsService:
    """数据统计聚合"""

    async def get_overview(self, target_date: date) -> dict:
        """数据总览

        - DAU：BITCOUNT stats:daurset:{yyyymmdd}
        - play_count：SELECT COUNT(*) FROM play_log WHERE DATE(played_at) = date
        - completion_rate：SELECT AVG(completed) FROM play_log WHERE DATE(played_at) = date
        - avg_listen_duration：SELECT AVG(duration) FROM play_log WHERE DATE(played_at) = date
        - ad_impression：当日 episode.play_count × 3（三段广告）
        """
        dau = await self.redis.bitcount(f"stats:daurset:{target_date.strftime('%Y%m%d')}")

        result = await self.db.execute(
            select(
                func.count(PlayLog.id).label("play_count"),
                func.avg(PlayLog.completed).label("completion_rate"),
                func.avg(PlayLog.duration).label("avg_listen_duration"),
            ).where(func.date(PlayLog.played_at) == target_date)
        )
        row = result.one()

        # 广告曝光 = 当日节目播放次数 × 3 段广告
        episode = await self._get_published_episode(target_date)
        ad_impression = (episode.play_count * 3) if episode else 0

        return {
            "dau": dau,
            "play_count": row.play_count or 0,
            "completion_rate": float(row.completion_rate or 0),
            "avg_listen_duration": int(row.avg_listen_duration or 0),
            "ad_impression": ad_impression,
        }

    async def get_trend(self, metric: str, range_days: int) -> dict:
        """趋势图（7d/30d/90d）"""
        end_date = date.today()
        start_date = end_date - timedelta(days=range_days - 1)

        if metric == "dau":
            # 从 Redis Bitmap 取多日数据
            dates = []
            values = []
            cur = start_date
            while cur <= end_date:
                key = f"stats:daurset:{cur.strftime('%Y%m%d')}"
                count = await self.redis.bitcount(key)
                dates.append(cur.isoformat())
                values.append(count)
                cur += timedelta(days=1)
            return {"dates": dates, "values": values}

        # 其他指标从 MySQL 聚合
        result = await self.db.execute(
            select(
                func.date(PlayLog.played_at).label("d"),
                {
                    "play_count": func.count(PlayLog.id),
                    "completion_rate": func.avg(PlayLog.completed),
                    "avg_listen_duration": func.avg(PlayLog.duration),
                }[metric].label("v"),
            )
            .where(PlayLog.played_at >= start_date)
            .group_by("d")
            .order_by("d")
        )
        rows = result.all()
        return {"dates": [r.d for r in rows], "values": [r.v for r in rows]}
```

```python
        - reject：打回 → workflow 置 failed，待运营决定是否备播
        - replace：标记问题段落 → 触发 LLM 重新改写该段 → 重新 TTS → 重新拼接 → 新 review 记录
        """
        review = await self._get_review(review_id)
        if review.status != "pending":
            raise BizError("该审核记录已处理")

        if action == "approve":
            review.status = "approved"
            review.reviewer_id = reviewer_id
            review.reviewer_name = reviewer_name
            review.reviewed_at = datetime.utcnow()
            await self.db.commit()
            # 触发发布
            await workflow_scheduler.publish(review.workflow_id, review.id)

        elif action == "reject":
            if not reason:
                raise BizError("reject 必须填写理由")
            review.status = "rejected"
            review.reason = reason
            review.reviewer_id = reviewer_id
            review.reviewer_name = reviewer_name
            review.reviewed_at = datetime.utcnow()
            await self.db.commit()
            # 工作流置 failed，等待 06:30 备播检查
            await workflow_scheduler._update_workflow_status(
                review.workflow_id, "failed", error=f"审核打回: {reason}"
            )

        elif action == "replace":
            if not reason or segment_id is None:
                raise BizError("replace 必须填写理由与段落序号")
            review.status = "replaced"
            review.reason = reason
            review.reviewer_id = reviewer_id
            review.reviewer_name = reviewer_name
            review.reviewed_at = datetime.utcnow()
            await self.db.commit()
            # 异步触发段落重新生成
            asyncio.create_task(
                self._regenerate_segment(review.workflow_id, review.script_id, segment_id, reason)
            )

    async def _regenerate_segment(self, workflow_id: str, script_id: int, segment_id: int, reason: str):
        """段落重新生成流程

        1. 调用 llm.rewrite_segment(script_id, segment_id, reason) 重新改写该段
        2. 重新 TTS 该段
        3. 重新拼接所有段
        4. 创建新 review 记录（status=pending）
        5. 通知运营重新审核
        """
        # 调用 LLM 局部重写
        new_segment = await llm.rewrite_segment(script_id, segment_id, reason)
        # 重新 TTS
        new_audio = await tts.synthesize_segment(new_segment["content"])
        # 重新拼接（需下载其他段音频 + 新段音频拼接）
        new_final_url = await stitch._rebuild_with_segment(script_id, segment_id, new_audio)
        # 创建新 review
        await self._create_new_review(workflow_id, script_id, new_final_url)
        await self._alert_operators(f"工作流 {workflow_id} 段 {segment_id} 已重新生成，请重新审核")
```

## 7. 关键算法实现

> 本章给出 SimHash 标题去重、热度计算、敏感词过滤、tenacity 重试策略等关键算法的可读伪代码与设计要点。

### 7.1 SimHash 标题去重

**模块路径**：`app/core/simhash.py`

**用途**：爬虫模块对素材标题做近似去重，避免不同源转发同一新闻重复爬取。

**算法选择理由**：相比严格 hash（一字之差判为不同），SimHash 对局部修改不敏感，相似输入产生相似指纹；通过汉明距离阈值即可判定近似重复，适合 MVP 的 50-100 条标题规模。

```python
import hashlib
import jieba

# 64 位 SimHash，对应 16 位十六进制字符串
BITS = 64


def compute(text: str) -> str:
    """计算文本的 SimHash 指纹

    流程：
    1. jieba 分词，得到词列表
    2. 每个词 MD5 哈希得 64 位整数
    3. 对每一位：该位为 1 则 +词频权重，为 0 则 -词频权重
    4. 累加后每一位 > 0 取 1，否则取 0，得 64 位指纹
    5. 转十六进制字符串返回
    """
    words = jieba.lcut(text)
    if not words:
        return "0" * 16

    # 词频统计（重复词权重更高）
    from collections import Counter
    word_weights = Counter(words)

    # 64 个位置的累加器
    accum = [0] * BITS

    for word, weight in word_weights.items():
        # MD5 取前 8 字节 = 64 位
        h = int(hashlib.md5(word.encode("utf-8")).hexdigest()[:16], 16)
        for i in range(BITS):
            if h & (1 << i):
                accum[i] += weight
            else:
                accum[i] -= weight

    # 累加结果符号化 → 64 位指纹
    fingerprint = 0
    for i in range(BITS):
        if accum[i] > 0:
            fingerprint |= (1 << i)

    # 转十六进制字符串（16 字符）
    return f"{fingerprint:016x}"


def hamming_distance(hash1: str, hash2: str) -> int:
    """计算两个 SimHash 指纹的汉明距离

    异或后统计 1 的个数即为汉明距离
    """
    n1 = int(hash1, 16)
    n2 = int(hash2, 16)
    return bin(n1 ^ n2).count("1")


def is_similar(hash1: str, hash2: str, threshold: int = 3) -> bool:
    """判断两个指纹是否近似重复

    64 位 SimHash 经验阈值：汉明距离 ≤ 3 视为相似
    阈值越小越严格（误判少但漏判多），越大越宽松（漏判少但误判多）
    MVP 取 3 是业界常用值，对中文新闻标题效果良好
    """
    return hamming_distance(hash1, hash2) <= threshold
```

**性能**：单次计算约 1ms（50 字符标题），50-100 篇素材两两比较 < 0.1s，可接受。

### 7.2 热度计算公式

**模块路径**：`app/workflow/llm/rewriter.py::_heat_score`

**公式**：

```
热度 = 源权威度 × 0.3 + 标题关键词热度 × 0.4 + 发布时间近度 × 0.3
```

**三项权重设计理由**：
- 标题关键词热度权重最高（0.4），因为标题最能反映新闻重要性；
- 源权威度与时间近度权重相当（0.3），保证权威源 + 时效性的基础分；
- 三项均归一化到 [0, 1]，最终热度也在 [0, 1]。

```python
from datetime import datetime, timedelta

# 热点关键词词表（运营维护，可配置）
HOT_KEYWORDS = {
    "突破": 0.9, "首发": 0.85, "独家": 0.8, "重磅": 0.95,
    "发布": 0.6, "上市": 0.7, "收购": 0.75, "融资": 0.65,
    "政策": 0.7, "改革": 0.65, "制裁": 0.85, "合作": 0.55,
    # ... 运营按热度定期更新
}


def _keyword_heat(title: str) -> float:
    """标题关键词热度：取标题中命中的最热关键词的分值

    多个关键词命中取最大值（避免叠加导致偏差）
    无命中返回 0.3（基础分，避免完全无分）
    """
    max_score = 0.0
    for keyword, score in HOT_KEYWORDS.items():
        if keyword in title:
            max_score = max(max_score, score)
    return max_score if max_score > 0 else 0.3


def _recency_score(published_at: datetime) -> float:
    """发布时间近度：越近分越高

    24 小时内：1.0 → 0.5 线性衰减
    24-48 小时：0.5 → 0.2 线性衰减
    48 小时以上：0.2 → 0.0 线性衰减
    """
    if not published_at:
        return 0.5                       # 无发布时间取中值
    delta = datetime.utcnow() - published_at
    hours = delta.total_seconds() / 3600
    if hours <= 24:
        return 1.0 - (hours / 24) * 0.5  # 1.0 → 0.5
    elif hours <= 48:
        return 0.5 - ((hours - 24) / 24) * 0.3  # 0.5 → 0.2
    elif hours <= 72:
        return 0.2 - ((hours - 48) / 24) * 0.2  # 0.2 → 0.0
    else:
        return 0.0


def _heat_score(material: dict) -> float:
    """综合热度计算

    三项加权：
    - 源权威度 30%：来源在 rss.yaml 配置，权威媒体如新华/人民 0.9，自媒体 0.5
    - 关键词热度 40%：标题命中热点关键词
    - 时间近度 30%：发布越近分越高
    """
    authority = material.get("source_authority", 0.5)
    keyword_heat = _keyword_heat(material["title"])
    recency = _recency_score(material.get("published_at"))
    return authority * 0.3 + keyword_heat * 0.4 + recency * 0.3
```

### 7.3 敏感词过滤

**模块路径**：`app/workflow/llm/sensitive_filter.py`

**算法选择**：MVP 用 AC 自动机（Aho-Corasick）多模式匹配，O(N) 一次扫描全文命中所有敏感词，比朴素遍历快几个数量级。

```python
import ahocorasick

# 敏感词表加载（启动时一次性构建自动机，运行时只查询）
_automaton = ahocorasick.Automaton()


def load_words(file_path: str) -> None:
    """从敏感词文件加载，构建 AC 自动机

    文件格式：每行一个敏感词，# 开头为注释
    启动时调用一次，敏感词更新后需重启应用或调 reload
    """
    global _automaton
    _automaton = ahocorasick.Automaton()
    with open(file_path, encoding="utf-8") as f:
        for idx, line in enumerate(f):
            word = line.strip()
            if word and not word.startswith("#"):
                _automaton.add_word(word, (idx, word))
    _automaton.make_automaton()


def contains(text: str) -> bool:
    """快速判断文本是否包含任一敏感词

    用于 LLM 改写结果扫描：命中即重新生成
    """
    for _, (_, word) in _automaton.iter(text):
        return True
    return False


def find_all(text: str) -> list[str]:
    """找出文本中所有敏感词

    用于运营后台展示具体命中位置
    """
    return [word for _, (_, word) in _automaton.iter(text)]


def replace(text: str, mask: str = "*") -> str:
    """将敏感词替换为掩码字符

    用于 LLM 二次生成仍命中时的兜底处理
    """
    result = list(text)
    for end_idx, (_, word) in _automaton.iter(text):
        start_idx = end_idx - len(word) + 1
        for i in range(start_idx, end_idx + 1):
            result[i] = mask
    return "".join(result)
```

**双层过滤策略**：

```python

```

### 7.4 重试策略（tenacity）

**模块路径**：分散在 `app/workflow/llm/rewriter.py`、`app/workflow/tts/synthesizer.py`

**设计原则**：
- 仅对**可重试错误**重试（网络超时、API 限流、临时不可用）；
- **不可重试错误**（参数错误、内容审核拒绝、鉴权失败）立即失败；
- 指数退避避免雪崩；最大重试 3 次（含首次），总耗时上限可控。

```python
from tenacity import (
    retry, stop_after_attempt, wait_exponential,
    retry_if_exception_type, before_sleep_log,
)
import logging

logger = logging.getLogger(__name__)


# 通义千问 API 可重试错误
class LLMRateLimitError(Exception):
    """API 限流（429）"""
class LLMTimeoutError(Exception):
    """请求超时"""
class LLMServiceError(Exception):
    """服务端 5xx"""

# 不可重试错误
class LLMAuthError(Exception):
    """鉴权失败（API key 错误）"""
class LLMContentError(Exception):
    """内容审核拒绝（输入或输出违规）"""


# LLM 重试装饰器
llm_retry = retry(
    stop=stop_after_attempt(3),                              # 最多 3 次
    wait=wait_exponential(min=1, max=10, multiplier=1),      # 1s, 2s, 4s... 上限 10s
    retry=retry_if_exception_type(
        (LLMRateLimitError, LLMTimeoutError, LLMServiceError)
    ),
    before_sleep=before_sleep_log(logger, logging.WARNING),  # 重试前打日志
    reraise=True,                                            # 重试耗尽后抛出原异常
)


@llm_retry
async def call_llm(prompt: str) -> str:
    """LLM 调用，带重试

    异常映射：
    - HTTP 429 → LLMRateLimitError（重试）
    - HTTP 401 → LLMAuthError（不重试）
    - HTTP 400 含 "content_filter" → LLMContentError（不重试）
    - 超时 → LLMTimeoutError（重试）
    - HTTP 5xx → LLMServiceError（重试）
    """
    try:
        resp = await client.chat.completions.create(...)
        return resp.choices[0].message.content
    except openai.RateLimitError as e:
        raise LLMRateLimitError(str(e))
    except openai.AuthenticationError as e:
        raise LLMAuthError(str(e))
    except openai.APITimeoutError as e:
        raise LLMTimeoutError(str(e))
    except openai.APIConnectionError as e:
        raise LLMServiceError(str(e))
    except openai.InternalServerError as e:
        raise LLMServiceError(str(e))


# TTS 模块类似配置
tts_retry = retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(min=1, max=10),
    retry=retry_if_exception_type(
        (TTSRateLimitError, TTSTimeoutError, TTSServiceError)
    ),
    reraise=True,
)
```

**重试场景对照表**：

| 错误类型 | 是否重试 | 重试次数 | 退避策略 | 失败后处理 |
| --- | --- | --- | --- | --- |
| 网络超时 | 是 | 3 | 1s, 2s, 4s | 步骤失败，启用备播 |
| API 限流 429 | 是 | 3 | 1s, 2s, 4s | 步骤失败，启用备播 |
| 服务端 5xx | 是 | 3 | 1s, 2s, 4s | 步骤失败，启用备播 |
| 鉴权失败 401 | 否 | — | — | 立即失败，告警运维 |
| 内容审核拒绝 | 否 | — | — | 改用约束 prompt 重生成一次 |
| 参数错误 400 | 否 | — | — | 立即失败，记录 bug |
| MySQL 死锁 | 是 | 3 | 立即重试 | 步骤失败，告警 |
| FFmpeg 失败 | 是 | 2 | 5s, 10s | 步骤失败，启用备播 |

```nginx
# 20_News Nginx 配置
# 功能：反向代理 + TLS + 静态资源分发 + 限流

worker_processes auto;
events {
    worker_connections 1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;

    # 日志格式
    log_format main '$remote_addr - $remote_user [$time_local] '
                    '"$request" $status $body_bytes_sent '
                    '"$http_referer" "$http_user_agent" rt=$request_time';
    access_log /var/log/nginx/access.log main;
    error_log  /var/log/nginx/error.log warn;

    sendfile        on;
    keepalive_timeout 65;
    client_max_body_size 50M;                # 广告素材上传限制（50MB）

    # 限流 zone（C 端 60 req/min/IP）
    limit_req_zone $binary_remote_addr zone=c_api:10m rate=60r/m;
    # B 端限流（120 req/min/IP）
    limit_req_zone $binary_remote_addr zone=b_api:10m rate=120r/m;

    # 上游 FastAPI 应用
    upstream fastapi_app {
        server app:8000;
        keepalive 32;
    }

    # HTTP → HTTPS 重定向
    server {
        listen 80;
        server_name api.example.com;
        return 301 https://$host$request_uri;
    }

    # HTTPS 主服务
    server {
        listen 443 ssl http2;
        server_name api.example.com;

        # TLS 证书（Let's Encrypt 或自签）
        ssl_certificate     /etc/nginx/ssl/fullchain.pem;
        ssl_certificate_key /etc/nginx/ssl/privkey.pem;
        ssl_protocols       TLSv1.2 TLSv1.3;
        ssl_ciphers         HIGH:!aNULL:!MD5;
        ssl_session_cache   shared:SSL:10m;
        ssl_session_timeout 10m;

        # C 端 API
        location /api/v1/ {
            limit_req zone=c_api burst=20 nodelay;
            proxy_pass http://fastapi_app;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_read_timeout 60s;
        }

        # B 端 API
        location /admin/api/v1/ {
            limit_req zone=b_api burst=40 nodelay;
            proxy_pass http://fastapi_app;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_read_timeout 60s;
        }

        # 内部工作流接口（仅允许 localhost）
        location /api/internal/ {
            allow 127.0.0.1;
            allow 172.16.0.0/12;              # Docker 内网
            deny all;
            proxy_pass http://fastapi_app;
            proxy_set_header Host $host;
            proxy_set_header X-Internal-Sign $http_x_internal_sign;  # HMAC 签名校验
        }

        # 健康检查（不限流）
        location /api/health {
            proxy_pass http://fastapi_app;
            access_log off;
        }

        # B 端运营后台静态资源（Vue 构建产物）
        location /admin/ {
            root /usr/share/nginx/html;
            try_files $uri $uri/ /admin/index.html;
            expires 1h;
        }

        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2?)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
        }
    }
}
```

### 9.7 `start.ps1` — PowerShell 一键启动脚本

```powershell
# 20_News 单机部署一键启动脚本
# 适用：Windows 10 + PowerShell + Docker Desktop
# 用法：.\start.ps1
# 注意：PowerShell 不支持 && 串联，使用 ; 或分行

param(
    [switch]$Build,        # 强制重新构建镜像
    [switch]$Reset         # 重置数据（删除 data 目录）
)

$ErrorActionPreference = "Stop"

Write-Host "========================================" -ForegroundColor Cyan
Write-Host "  20_News 单机部署启动脚本" -ForegroundColor Cyan
Write-Host "========================================" -ForegroundColor Cyan

# 1. 检查 Docker Desktop 是否运行
Write-Host "`n[1/6] 检查 Docker Desktop..." -ForegroundColor Yellow
$dockerStatus = docker info 2>&1
if ($LASTEXITCODE -ne 0) {
    Write-Host "Docker Desktop 未运行，正在启动..." -ForegroundColor Yellow
    Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
    Write-Host "等待 Docker Desktop 启动完成（60秒）..." -ForegroundColor Yellow
    Start-Sleep -Seconds 60
    docker info | Out-Null
    if ($LASTEXITCODE -ne 0) {
        Write-Host "ERROR: Docker Desktop 启动失败，请手动启动后重试" -ForegroundColor Red
        exit 1
    }
}
Write-Host "Docker Desktop 运行正常" -ForegroundColor Green

# 2. 检查 .env 文件
Write-Host "`n[2/6] 检查 .env 配置..." -ForegroundColor Yellow
if (-not (Test-Path .env)) {
    if (Test-Path .env.example) {
        Write-Host ".env 不存在，从 .env.example 复制..." -ForegroundColor Yellow
        Copy-Item .env.example .env
        Write-Host "WARNING: 请编辑 .env 填入实际配置后重新运行此脚本" -ForegroundColor Red
        Write-Host "  notepad .env" -ForegroundColor Gray
        exit 1
    } else {
        Write-Host "ERROR: .env 与 .env.example 均不存在" -ForegroundColor Red
        exit 1
    }
}
Write-Host ".env 配置存在" -ForegroundColor Green

# 3. 可选：重置数据
if ($Reset) {
    Write-Host "`n[3/6] 重置数据（删除 data 目录）..." -ForegroundColor Yellow
    docker-compose down -v
    Remove-Item -Recurse -Force data -ErrorAction SilentlyContinue
    Write-Host "数据已重置" -ForegroundColor Green
} else {
    Write-Host "`n[3/6] 保留现有数据" -ForegroundColor Green
}
```

### 10.2 `miniprogram/services/api.js` — API 封装

```javascript
// services/api.js
// 统一请求封装：token 注入、401 自动重登、统一响应格式处理
const { getToken, refreshToken } = require('./auth');

const BASE_URL = 'https://api.example.com/api/v1';

async function request(options) {
  const { url, method = 'GET', data, header = {} } = options;

  // 注入 token
  const token = getToken();
  if (token) {
    header.Authorization = `Bearer ${token}`;
  }

  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE_URL + url,
      method,
      data,
      header: { 'Content-Type': 'application/json', ...header },
      success: async (res) => {
        // 401 自动重登一次
        if (res.statusCode === 401) {
          try {
            await refreshToken();
            // 重试原请求
            const retry = await request(options);
            resolve(retry);
          } catch (e) {
            reject(new Error('登录已失效，请重新打开小程序'));
          }
          return;
        }
        // 业务错误（code != 0）
        if (res.data.code !== 0) {
          reject(new Error(res.data.message || '请求失败'));
          return;
        }
        resolve(res.data.data);
      },
      fail: (err) => reject(new Error('网络异常')),
    });
  });
}

// 各接口封装
const fetchTodayEpisode = () => request({ url: '/episodes/today' });
const fetchEpisodeDetail = (id) => request({ url: `/episodes/${id}` });
const fetchEpisodeScript = (id) => request({ url: `/episodes/${id}/script` });
const fetchHistory = (page, size = 20) =>
  request({ url: '/episodes/history', data: { page, size } });
const reportPlayProgress = (data) =>
  request({ url: '/playlogs/progress', method: 'POST', data });
const fetchPlayProgress = (episodeId) =>
  request({ url: `/playlogs/progress/${episodeId}` });

module.exports = {
  request, fetchTodayEpisode, fetchEpisodeDetail,
  fetchEpisodeScript, fetchHistory, reportPlayProgress, fetchPlayProgress,
};
```

### 10.3 `miniprogram/services/auth.js` — 登录鉴权

```javascript
// services/auth.js
// 微信登录流程：wx.login → 后端换 token → 本地缓存
const STORAGE_KEY_TOKEN = 'news_token';
const STORAGE_KEY_USER = 'news_user';

function getToken() {
  return wx.getStorageSync(STORAGE_KEY_TOKEN);
}

function setToken(token, user) {
  wx.setStorageSync(STORAGE_KEY_TOKEN, token);
  wx.setStorageSync(STORAGE_KEY_USER, user);
}

function clearToken() {
  wx.removeStorageSync(STORAGE_KEY_TOKEN);
  wx.removeStorageSync(STORAGE_KEY_USER);
}

// 登录：wx.login 获取 code → 调后端换 token
function login() {
  return new Promise((resolve, reject) => {
    wx.login({
      success: async (res) => {
        if (!res.code) {
          reject(new Error('wx.login 未返回 code'));
          return;
        }
        // 调后端 /auth/login
        wx.request({
          url: 'https://api.example.com/api/v1/auth/login',
          method: 'POST',
          data: { code: res.code },
          success: (resp) => {
            if (resp.data.code === 0) {
              setToken(resp.data.data.token, resp.data.data.user);
              resolve(resp.data.data);
            } else {
              reject(new Error(resp.data.message));
            }
          },
          fail: (err) => reject(err),
        });
      },
      fail: (err) => reject(err),
    });
  });
}

// 刷新 token（401 时自动调用，实际是重新 wx.login）
async function refreshToken() {
  clearToken();
  const { token, user } = await login();
  return { token, user };
}

// 登出
async function logout() {
  // 调后端登出接口（写 Redis 黑名单）
  const token = getToken();
  if (token) {
    wx.request({
      url: 'https://api.example.com/api/v1/auth/logout',
      method: 'POST',
      header: { Authorization: `Bearer ${token}` },
      complete: () => {
        clearToken();
      },
    });
  }
}

module.exports = { getToken, setToken, clearToken, login, refreshToken, logout };
```

### 10.4 `miniprogram/services/audio.js` — 全局播放器

```javascript
// services/audio.js
// 全局音频播放器：基于 wx.getBackgroundAudioManager 单例
// 支持：锁屏播放、断点续播、进度上报、来电暂停
const { reportPlayProgress, fetchPlayProgress } = require('./api');

let audioManager = null;
let progressTimer = null;     // 进度上报定时器
let currentEpisode = null;    // 当前播放的节目

function initPlayer() {
  if (audioManager) return audioManager;

  audioManager = wx.getBackgroundAudioManager();

  // 播放结束：标记完播，上报
  audioManager.onEnded(() => {
    if (currentEpisode) {
      reportPlayProgress({
        episode_id: currentEpisode.id,
        position: audioManager.duration,
        duration: audioManager.duration,
        completed: true,
      });
    }
    stopProgressReport();
  });

  // 播放暂停：停止进度上报
  audioManager.onPause(() => {
    stopProgressReport();
    // 暂停时立即上报一次当前位置
    if (currentEpisode) {
      reportPlayProgress({
        episode_id: currentEpisode.id,
        position: audioManager.currentTime,
        duration: audioManager.duration,
        completed: false,
      });
    }
  });

  // 播放恢复：重启进度上报
  audioManager.onPlay(() => {
    startProgressReport();
  });

  // 播放错误
  audioManager.onError((err) => {
    console.error('播放错误', err);
    wx.showToast({ title: '音频加载失败', icon: 'none' });
  });

  return audioManager;
}

// 播放指定节目（自动断点续播）
async function playEpisode(episode) {
  currentEpisode = episode;

  // 查询上次播放进度（断点续播）
  let startPosition = 0;
  try {
    const progress = await fetchPlayProgress(episode.id);
    if (progress && progress.position > 0 && !progress.completed) {
      startPosition = progress.position;
    }
  } catch (err) {
    console.warn('获取播放进度失败，从开头播放', err);
  }

  // 设置播放源（title 必填，否则锁屏不显示）
  audioManager.title = episode.title;
  audioManager.epname = episode.title;
  audioManager.src = episode.audio_url;

  // 跳转到上次位置（需等待音频元数据加载完成）
  if (startPosition > 0) {
    audioManager.onCanplay(() => {
      audioManager.seek(startPosition);
    });
  }
}

// 启动进度上报（每 5 秒一次）
function startProgressReport() {
  stopProgressReport();
  progressTimer = setInterval(() => {
    if (currentEpisode && audioManager.duration > 0) {
      reportPlayProgress({
        episode_id: currentEpisode.id,
        position: Math.floor(audioManager.currentTime),
        duration: Math.floor(audioManager.duration),
        completed: false,
      });
    }
  }, 5000);
}

function stopProgressReport() {
  if (progressTimer) {
    clearInterval(progressTimer);
    progressTimer = null;
  }
}

module.exports = { initPlayer, playEpisode, stopProgressReport };
```

```javascript
// src/api/index.js
// B 端 API 封装：axios + JWT 拦截器 + 统一错误处理
import axios from 'axios';
import { useUserStore } from '../stores/user';
import router from '../router';

const api = axios.create({
  baseURL: '/admin/api/v1',
  timeout: 15000,
});

// 请求拦截：注入 token
api.interceptors.request.use((config) => {
  const userStore = useUserStore();
  if (userStore.token) {
    config.headers.Authorization = `Bearer ${userStore.token}`;
  }
  return config;
});

// 响应拦截：统一错误处理
api.interceptors.response.use(
  (response) => {
    if (response.data.code !== 0) {
      return Promise.reject(new Error(response.data.message));
    }
    return response.data.data;
  },
  (error) => {
    if (error.response?.status === 401) {
      // token 失效，跳转登录
      const userStore = useUserStore();
      userStore.clearToken();
      router.push('/login');
    } else if (error.response?.status === 403) {
      ElMessage.error('无权限执行此操作');
    } else {
      ElMessage.error(error.response?.data?.message || '请求失败');
    }
    return Promise.reject(error);
  }
);

export default api;
```

```javascript
import { defineStore } from 'pinia';
import api from '../api';

export const useUserStore = defineStore('user', {
  state: () => ({
    token: localStorage.getItem('admin_token') || '',
    username: localStorage.getItem('admin_username') || '',
    role: localStorage.getItem('admin_role') || '',
  }),

  getters: {
    isLoggedIn: (state) => !!state.token,
    isAdmin: (state) => state.role === 'admin',
  },

  actions: {
    async login(username, password, captcha) {
      const data = await api.post('/auth/login', { username, password, captcha });
      this.token = data.token;
      this.username = data.username;
      this.role = data.role;
      localStorage.setItem('admin_token', data.token);
      localStorage.setItem('admin_username', data.username);
      localStorage.setItem('admin_role', data.role);
    },

    async logout() {
      try {
        await api.post('/auth/logout');
      } finally {
        this.clearToken();
      }
    },

    clearToken() {
      this.token = '';
      this.username = '';
      this.role = '';
      localStorage.removeItem('admin_token');
      localStorage.removeItem('admin_username');
      localStorage.removeItem('admin_role');
    },
  },
});
```
