来源：T02502（全站引导锚点契约改造）

## 背景
T02502 把引导选择器收敛为「显式锚点」契约：只允许 `[data-guide="x"]` / `[aria-label="x"]`，并禁止位置兜底（`.top-bar .el-button` 这类组合选择器会在真实锚点缺失时静默命中别的元素）。全站 27 条路由 / 58 步已按此改造，运行时审计（`apps/admin-web/scripts/guide-anchor-audit.mjs`）确认未命中 0。

唯一例外是 `/materials`（素材录入，视图 `apps/admin-web/src/views/channel/CourseMaterials.vue`）：该文件当时被并发会话持有未提交改动，无法插入 `data-guide` 属性（path-limited commit 会把对方 WIP 一起提交）。故该页两步暂用视图内唯一的语义类 `.page-container`（页面根容器）与 `.el-upload`（默认 tab 的拖拽上传区），并在 `apps/admin-web/scripts/validate-nav.mjs` 的 `BARE_CLASS_EXCEPTIONS` 例外登记表里显式登记。

## 待办
1. 待 CourseMaterials.vue 的并发改动落地后，给根容器加 `data-guide="materials-page"`、给上传拖拽区加 `data-guide="materials-upload"`（可再加 `materials-tabs`）。
2. `src/guide/guideConfig.js` 的 `/materials` 两步改用上述 `data-guide` 锚点，删掉注释里的例外说明。
3. 删除 `scripts/validate-nav.mjs` 中 `BARE_CLASS_EXCEPTIONS['/materials']` 条目（登记表清空后，建议把常量与相关分支一并删除，让门禁只认 data-guide/aria-label）。
4. 跑 `node scripts/guide-anchor-audit.mjs --routes=/materials`（需 dev server 5181）要求「未命中 0」，再跑 `npm run validate:nav` 与 `npm run build`。

## 验收
- `grep -n "s: \['[^[]" src/guide/guideConfig.js` 无输出（全站不再裸类选择器）。
- 引导浮层在素材录入页高亮的是页面根容器与上传区，文案与界面一致。
