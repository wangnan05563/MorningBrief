来源：T02502（全站引导锚点契约改造）

## 背景
T02502 把引导选择器收敛为「显式锚点」契约（`D:\code\otherProjects\20_News\apps\admin-web\src\guide\guideConfig.js` 头部有完整约定）：
每步只允许一个选择器，必须是 `[data-guide="x"]` 或 `[aria-label="x"]`，禁位置兜底与可能多实例的裸类；
构建期由 `D:\code\otherProjects\20_News\apps\admin-web\scripts\validate-nav.mjs` 校验，运行时由
`D:\code\otherProjects\20_News\apps\admin-web\scripts\guide-anchor-audit.mjs` 逐条审计。
全站 27 条路由 / 59 步已按此改造，审计结果「未命中 0 · 标题漂移 0」。

唯一例外是 `/materials`（素材录入，视图 `D:\code\otherProjects\20_News\apps\admin-web\src\views\channel\CourseMaterials.vue`）：
该文件当时被并发会话持有未提交改动，无法插入 `data-guide` 属性（path-limited commit 会把对方 WIP 一起提交）。
故该页两步暂用 `validate-nav.mjs` 中 `PAGE_UNIQUE_CLASSES` 白名单里的「全页唯一布局类」：
`.page-container`（页面根容器）与 `.el-upload`（默认 tab 的拖拽上传区），运行时审计已确认命中正确。

## 待办
1. 待 CourseMaterials.vue 的并发改动落地后，给根容器加 `data-guide="materials-page"`、给上传拖拽区加 `data-guide="materials-upload"`。
2. `src/guide/guideConfig.js` 的 `/materials` 两步改用上述 `data-guide` 锚点，并删掉那条「并发会话正在改这个文件」的注释。
3. 从 `scripts/validate-nav.mjs` 的 `PAGE_UNIQUE_CLASSES` 中移除 `.page-container` 与 `.el-upload`；
   若移除后集合为空，就把该常量与 `anchorProblem()` 里的裸类分支一起删掉，让门禁只认 data-guide/aria-label。
   这一步是本单的真正目的——白名单留着，后面的人会往里加类，门禁就退化成兜底通道。
4. 跑 `node scripts/guide-anchor-audit.mjs --routes=/materials`（需 dev server；在 git-bash 下加 `MSYS_NO_PATHCONV=1` 否则 `--routes=/x` 会被转成 Windows 路径）要求「未命中 0」；
   再跑 `npm run test:nav`、`npm run validate:nav`、`npm run build`。
