## 根因

本任务是对 news（MorningBrief）全部菜单做逐菜单 UX 评审。原任务的输入素材（截图/录屏/用户反馈）未提供，因此评审基准取**源码走查（只读）**：以 `apps/admin-web/src/router/index.js` 的 `meta.title/icon/group/hidden/requireRole` 为菜单权威源，覆盖 PC 27 个可见菜单 + 2 个 hidden 子页 + 移动端 `/m/*` 13 页 + 小程序 18 页 + 壳层/引导/登录/弹窗空态，共 **94 个界面小节**。

走查后归纳出 7 类跨菜单系统性根因（报告 §12），它们解释了 142 条高危中的大部分：

- **R1 反馈通道静默丢弃**：`apps/admin-web/src/utils/message.js:16-45` 在 `document.hidden || _isRestoring`（页面刚恢复的 2 秒内）时把所有 `ElMessage` 直接 `return` 掉、不排队不补发；`src/api/index.js:52-71` 的错误提示又受 `!error.config?.silent` 门控。两者叠加＝「后台标签页里发生的一切错误都不存在」，各菜单的失败态因此普遍表现为空态或正常态。
- **R2 加载失败回落默认值后保存即覆写**：`views/cos/CosConfig.vue:198-209,214-220` 把 `loadConfig` 的异常 catch 掉、表单留在初值 `bucket=''`，而保存请求无条件携带该字段，后端 `cos_config_service.py:139-143` 无条件覆写——一次网络抖动后点保存就把已持久化的 Bucket/CDN 域名清空。
- **R3 脱敏值被当真实数据回写（最严重）**：`backend/app/services/db_admin_service.py:129-140` 的 `_mask_sensitive()` 把 `password_hash`/`token`/`secret` 与命中关键词的 `ai_config.config_value` 显示成字面量 `"***"`；前端 `views/maintenance/DatabaseAdmin.vue:496-503` 用 `formData.value = {...row}` 整行预填、`:390` 的 `editableColumns` 含全部列，保存时 `db_admin_service.py:298-315` 的 `update_row` 只过滤 `None` 与 `""`、**不识别 `"***"`**。结果：对 `admin_user`/`ai_config` 任一行点「确认」（哪怕只改简介）就会把密码哈希或 API Key 写成 `***`，账号当场无法登录、密钥作废，界面还提示「更新成功」。`import_rows`（`:434`）同样没有敏感列过滤，与页面文案「敏感字段会被忽略」矛盾。
- **R4 前端与后端实现漂移**：`backend/app/models/review.py:13-25` 有 4 个状态（含 `replaced`）而 `views/review/ReviewList.vue:4-6` 只给 3 个 tab；`guide/guideConfig.js:69-71` 的引导第 2 步锚点 `[aria-label="立即触发一期工作流"]` 在 `views/workflow/WorkflowList.vue` 全文无 `aria-label`，回落选择器会把用户指向「重置」按钮；`views/about/About.vue:206-213` 仍是 5 个 `https://example.com/…` + `mailto:dev@example.com` 占位外链；帮助文档 8 处指向不存在的菜单；`router/index.js:8-15` 的分组注释漏「云端存储」。
- **R5 统计口径与单位**：`backend/app/models/play_log.py:32` 的 `duration` 是秒，`stats_service.py:53-56,86-87` 直接 `func.avg` 后原样返回，`views/stats/StatsOverview.vue:84` 却标「平均收听(分钟)」——60 倍量级误读，同类问题遍布数据分析 4 个菜单。
- **R6 长任务缺超时/断流/收尾**：`views/ai/KnowledgeQA.vue:498` 的 `api.post('/ai/chat')` 未覆盖全局 `timeout: 15000`，而后端模型调用本身以分钟计；`api/assistant.js:21,29` 已给同类接口设 120000，说明是漏配而非设计。
- **R7 高危动作缺确认或点了没反应**：`views/mobile/ManageAlert.vue:50-62` 应急停服 `prompt` 解构出 `value` 却使用 `v.trim()`（`v` 是 `inputValidator` 形参名、不在作用域）→ `ReferenceError` 被裸 `catch { return }` 吞掉，确认按钮永远没有反应；`views/system/AutoReviewConfig.vue` 自动审批开启零护栏；广告「停用」在 PC 端不可用且停用后 C 端 `get_active_placements` 不过滤 `enabled`。
