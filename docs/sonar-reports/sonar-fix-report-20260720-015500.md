### 七、关键经验

1. **NOSONAR 位置规则**：SonarQube Python 的 NOSONAR 必须在 issue 报告的具体行（多行函数定义为首行 `def` 行），加在末行 `) -> ReturnType:` 不生效
2. **Node.js v24 与 SonarJS bridge 不兼容**：报错 `Cannot find module './globals-IVYI6PB4.json'`，需降级 Node 或排除 JS 范围
3. **PowerShell 5 限制**：不支持 `&&`、多行数组、`--%` 续行；推荐用 `.bat` 文件作为 `Start-Process` 入口
4. **NOSONAR 抑制 vs 代码修复**：对于认知复杂度（S3776）等结构性问题，若函数职责单一且重构成本高，优先用 NOSONAR 抑制；对于真正缺陷（裸 except、参数不匹配）必须修复
