## 六、发现的问题及处理

### 问题 1：main.py 导入缺失（已修复）

| 项 | 内容 |
|---|---|
| 分类 | code_defect |
| 严重级别 | FAIL |
| 现象 | 服务启动报 `NameError: name 'RequestIdMiddleware' is not defined`，随后报 `setup_logging is not defined` |
| 根因 | [main.py](file:///d:/code/otherProjects/20_News/backend/app/main.py) 使用了 `RequestIdMiddleware` 和 `setup_logging` 但未导入 |
| 修复 | 添加 `from app.middleware.request_id import RequestIdMiddleware` 和 `from app.core.logging_setup import setup_logging` |
| 验证 | 修复后服务正常启动，健康检查通过 |
| 备注 | 此为既有代码缺陷，非本次数据库维护模块开发引入 |

### 问题 2：config.yaml 审计日志路径错误（已修复）

| 项 | 内容 |
|---|---|
| 分类 | code_defect |
| 严重级别 | WARN |
| 现象 | 测试配置中审计日志路径为 `/audit-logs`（复数），后端路由为 `/audit-log`（单数） |
| 修复 | 修正 [config.yaml](file:///d:/code/otherProjects/20_News/.trae/skills/news-auto-testing/config.yaml) 中路径为 `/audit-log` |
