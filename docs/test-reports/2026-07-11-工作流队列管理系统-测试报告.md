### 已修复的代码缺陷

1. **ImportError: cannot import name 'fail'**
   - 文件：backend/app/routers/admin/queue.py, channels.py
   - 原因：导入了不存在的 `fail` 函数
   - 修复：替换为 `error` 函数（app.core.response 中实际导出的函数）

2. **OperationalError: no such column: workflow.channel_id**
   - 文件：backend/data/news.db
   - 原因：ORM 模型新增了 channel_id/priority 列但未执行数据库迁移
   - 修复：执行 SQLite ALTER TABLE 添加列 + CREATE TABLE 创建新表
