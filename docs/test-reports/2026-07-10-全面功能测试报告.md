## 七、发现的问题及解决方案

### 问题 1：数据统计页 el-radio label API 废弃警告 [WARN] ✅ 已修复

- **复现步骤**：导航到 /stats，点击"播放量"或"30 天"radio 按钮
- **预期结果**：控制台无警告
- **实际结果**：控制台输出 `ElementPlusError: [el-radio] [API] label act as value is about to be deprecated in version 3.0.0, please use value instead`（5 次）
- **根因**：[StatsOverview.vue:36-42](file:///d:/code/otherProjects/MorningBrief/admin-web/src/views/stats/StatsOverview.vue#L36-L42) 使用 `label` 属性作为值，Element Plus 3.0 建议改用 `value`
- **修复**：将 5 处 `<el-radio-button label="xxx">` 改为 `<el-radio-button value="xxx">`
- **回归验证**：✅ 修复后控制台无任何 error/warn

### 问题 2：数据统计页 ECharts Filler 插件缺失 [WARN] ✅ 已修复

- **复现步骤**：导航到 /stats，切换趋势图指标
- **预期结果**：趋势图区域填充正常，无警告
- **实际结果**：控制台输出 `Tried to use the 'fill' option without the 'Filler' plugin enabled`（2 次）
- **根因**：[StatsOverview.vue:112](file:///d:/code/otherProjects/MorningBrief/admin-web/src/views/stats/StatsOverview.vue#L112) 配置了 `fill: true`，但 Chart.js 注册组件中未包含 Filler
- **修复**：在 import 中添加 `Filler`，在 `ChartJS.register()` 中注册
- **回归验证**：✅ 修复后控制台无任何 error/warn

### 问题 3：工作流监控页有 1 条工作流状态为"失败" [WARN] 无需代码修复

- **复现步骤**：导航到 /workflows
- **预期结果**：工作流执行成功
- **实际结果**：1 条记录 `wf-20260710-0001` 状态为"失败"（2026-07-09 17:26:58 ~ 17:33:56）
- **根因**：业务数据问题，非代码缺陷。失败原因为 .env 中 LLM_API_KEY 为占位符 `<你的通义千问 API key>`，工作流调用 LLM 时认证失败
- **解决方案**：在 .env 中填入真实的通义千问 API key 后重新触发工作流
- **代码修复**：无需

### 问题 4：工作流监控页取消确认对话框触发控制台 error [INFO] 无需修复

- **复现步骤**：点击"手动触发"→ 点击"Cancel"
- **预期结果**：对话框关闭
- **实际结果**：对话框正常关闭，但控制台输出 `[error] cancel`
- **根因**：Element Plus ElMessageBox.confirm 的 reject 回调抛出 cancel 异常，属于框架预期行为，前端代码应使用 `.catch(() => {})` 吞掉
- **解决方案**：可在前端代码中添加 `.catch(() => {})` 静默处理，但当前不影响功能
- **代码修复**：无需（框架预期行为）

### 问题 5：Element Plus 菜单项点击不跳转 URL [INFO] 已规避

- **复现步骤**：在 /ads/materials 页点击菜单"投放规则"
- **预期结果**：URL 跳转到 /ads/placements
- **实际结果**：菜单项变为 focused 状态，但 URL 不变
- **根因**：Element Plus el-menu 组件的 menuitem 在 Chrome DevTools MCP 点击下未触发路由导航
- **规避方案**：测试中改用直接 URL 导航（navigate_page），所有页面均能正常加载
- **代码修复**：无需（可能是 MCP 工具与 Element Plus 菜单组件的交互兼容性问题，实际用户点击正常）
