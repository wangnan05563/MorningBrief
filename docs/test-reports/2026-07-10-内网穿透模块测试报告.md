## 四、发现的问题及修复

### 问题 1：/tunnel 页面 reload 后 500 错误 [FAIL] ✅ 已修复

- **复现步骤**：在 /tunnel 页面执行 navigate_page（reload）
- **预期结果**：页面正常加载
- **实际结果**：控制台报 `Failed to load resource: the server responded with a status of 500 (Internal Server Error) [2 times]`
- **根因分析**：
  - 后端日志 `logs/service-start.log.err` 显示 `FileNotFoundError: [WinError 3] 系统找不到指定的路径。: 'D:\code\otherProjects\MorningBrief\admin-web\dist\index.html'`
  - 服务启动时 `admin-web/dist` 存在（SPA fallback 路由已注册），但运行期间前端重新构建时 Vite 先清空了 dist 目录，导致 FileResponse 找不到 index.html
- **修复方案**：重新执行 `npm run build` 恢复 dist 目录
- **回归验证**：
  - navigate_page 到 /tunnel → 页面正常加载 ✅
  - list_console_messages → 无任何 error ✅
  - list_network_requests → /tunnel/status 200, /tunnel/config 200 ✅
