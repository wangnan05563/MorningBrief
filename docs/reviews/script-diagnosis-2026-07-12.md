# 20_News 启动脚本问题复盘

## 一、成功执行任务的完整步骤

### 阶段 1：端口占用诊断
1. 读取错误日志 → 定位 `[Errno 10048]` 端口绑定失败
2. netstat 确认 8000 端口被 PID 30376 占用
3. 健康检查确认服务正常运行（200 OK）
4. 结论：重复启动导致端口冲突，非 SQLite/COS/EventBus 故障

### 阶段 2：start.ps1 端口冲突保护
1. 读取 start.ps1 旧实例清理逻辑（第 178-215 行）
2. 发现端口清理写死 8000，但启动后才读取 .env 配置
3. 修复：启动前从 .env 读取 APP_PORT → 端口检测使用动态变量 → 清理后二次检查 → 占用则终止
4. 编写回归测试：start-script.Tests.ps1（ASCII 匹配）
5. 验证：PowerShell 语法检查 + 真实端口占用场景正确退出

### 阶段 3：.bat 编码问题修复
1. 诊断桌面快捷方式报错 → 分析碎片化命令
2. 读取字节前 3 字节 → 确认无 BOM
3. 统计孤立 LF 数 → 32 个
4. 根因：GBK 编码中文 + LF 行尾被 cmd 错误切分
5. 修复：转 GBK + CRLF → 改为纯 ASCII 入口脚本
6. 验证：bat-encoding.Tests.ps1 + cmd.exe 冒烟测试 + 桌面快捷方式确认

### 阶段 4：窗口与日志输出修复
1. 诊断症状：启动脚本执行后直接退出，无日志打印窗口
2. 修复：.bat 末尾添加 `pause >nul` → start.ps1 改 `WindowStyle Normal` + 实时输出
3. 验证：双击快捷方式 → 2 个可见 cmd 窗口 + 健康检查 200 OK
