# 隐私政策

> 单一来源：`apps/miniprogram/pages/privacy/privacy.js`（V1.3 · FR-SUP-11）。
> 改文本请改小程序常量后运行 `node scripts/legal-docs.mjs --write` 重新生成本文件；
> `npm run test:unit` 的 legal-docs-consistency 用例会逐字比对两侧，任一侧漂移即红。
> 后台（admin-web）关于页不设政策入口，本目录仅供审阅与追溯（T02690 裁决）。

## 一、信息收集

本应用仅收集以下信息：1) 微信 openid（用于身份识别）；2) 播放进度与收听统计（用于断点续播与个性化）；3) 您主动提交的反馈内容与联系方式。我们不收集您的微信密码、支付信息等敏感数据。

## 二、信息使用

收集的信息仅用于：1) 提供播放进度同步、收藏等功能；2) 改进播报内容与算法；3) 处理您的反馈与建议。我们不会将您的信息用于其他商业用途。

## 三、信息存储与保护

您的数据存储在应用服务器中，我们采取合理的技术与管理措施保护您的信息安全。播放日志中的 IP 地址仅用于风控反刷，不会长期保留。

## 四、信息共享

我们不会向第三方出售、出租您的个人信息。仅在以下情形下可能共享：1) 获得您的明确同意；2) 法律法规要求；3) 为完成您请求的服务必须共享（如支付通道）。

## 五、Cookie 与缓存

本应用用微信小程序本地缓存保存：登录态、播放与通知设置、搜索历史、下载索引、上次播放项，以及收藏/进度/偏爱的离线副本。其中收藏、播放进度与播放历史会同步保存在服务器（用于换设备后继续收听），搜索历史与下载索引只存在您的设备上。「设置 → 存储管理 → 清除缓存」只清可再生的技术缓存（例如上次探测到的服务地址），上面这些本机数据一项都不会被它清掉；它同样不会删除服务器上的数据。

## 六、未成年人保护

本应用主要面向成年用户。如发现未成年人在未经监护人同意的情况下使用本应用，我们将采取措施删除相关信息。

## 七、您的权利

您有权：1) 查询自己的个人信息——收藏、播放历史与「我的」页的收听分钟/期数统计均可在应用内查看；2) 要求更正错误信息；3) 要求删除个人信息——「设置 → 数据与统计 → 删除我的数据」可自助删除您名下的收藏、评论、点赞、播放记录与进度、频道与消息订阅，并同时清除本机登录态与离线副本；删除立即作用于当前数据库，但每日数据库备份保留 7 天、云端备份最多保留 5 份，过期后自动清除，因此无法立即彻底抹除；意见反馈记录不在自助删除范围内，如需删除请通过「我的 → 意见反馈」写明范围，我们收到后人工处理；4) 关闭使用统计——见「设置 → 数据与统计 → 记录使用统计」，关闭后本机不再记录页面浏览与按钮点击等操作事件；收藏与播放进度属于断点续传必须同步的功能数据，不在该开关的控制范围内。

## 八、政策变更

本应用保留修改本隐私政策的权利。重大变更将在应用内显著位置通知，您继续使用即视为同意修改后的政策。
