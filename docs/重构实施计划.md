### 2.1 P0 严重冲突（阻碍开发，必须立即修复）

#### P0-1：SRS TTS 技术选型与 HLD 严重冲突

**位置**：SRS 第 282 行、第 286 行
**问题**：
- SRS V1.1 FR-WORKFLOW-04 仍写"技术选型 | 自研部署 CosyVoice / GPT-SoVITS / IndexTTS 2.0 之一"
- SRS V1.1 FR-WORKFLOW-04 仍写"合成耗时 | 单次 ≤ 5 分钟（GPU 加速）"

#### P0-2：SRS TTS 音色方案与 HLD 冲突

**位置**：SRS 第 280 行、第 281 行、第 913 行
**问题**：
- SRS V1.1 FR-WORKFLOW-04 仍写"音色方案 | 克隆真人主播音色（推荐女声），带情感语调"
- SRS V1.1 FR-WORKFLOW-04 仍写"音色样本 | 录制 1 位主播 5-10 分钟多情绪样本，用于一次性音色克隆"
- SRS 10.5.1 仍写"技术成熟：CosyVoice、GPT-SoVITS、IndexTTS 2.0 等开源方案，5-10 秒样本即可克隆"
- HLD V1.5 已改为"阿里云内置优质神经语音（小芸），不做本地音色克隆"

**影响**：音色方案完全不同，影响 TTS 模块设计、成本估算、运维方案。
**修改建议**：
- SRS FR-WORKFLOW-04 音色方案改为："使用阿里云内置优质神经语音（推荐小芸女声），带情感语调"
- SRS FR-WORKFLOW-04 删除"音色样本"行或改为"如需定制音色，阿里云支持上传样本训练（按次付费，二期评估）"
- SRS 10.5.1 重写推荐理由，删除 CosyVoice/GPT-SoVITS/IndexTTS 2.0 相关描述

#### P0-3：SRS 与 HLD 工作流总耗时指标不一致

**位置**：SRS 第 442 行 NFR-PERF-05；HLD 第 1743 行 11.1
**问题**：
- SRS NFR-PERF-05："工作流总耗时 | 爬取到发布 ≤ 120 分钟"
- HLD 11.1："工作流总耗时 | ≤ 25 分钟（05:00-05:25）"
- 25 分钟只是爬取到拼接完成（不含审核等待），120 分钟含审核+发布，但表述不清导致歧义

**影响**：验收标准不明确，无法判断是否达标。
**修改建议**：
- SRS NFR-PERF-05 拆分为两个指标：
  - NFR-PERF-05a："工作流生产耗时（爬取到拼接完成）≤ 25 分钟"
  - NFR-PERF-05b："工作流端到端耗时（爬取到 07:00 发布）≤ 120 分钟"
- HLD 11.1 对齐 SRS，明确"25 分钟为生产阶段，不含审核等待"

#### P0-4：HLD 13.1 时序图仍引用 MySQL 和 Redis

**位置**：HLD 第 1819 行、第 1824 行、第 1834 行、第 1847 行
**问题**：
- 第 1819 行："store to MySQL material 表" → 应为 SQLite
- 第 1824 行："store script to MySQL" → 应为 SQLite
- 第 1834 行："query ad placements (Redis)" → 应为内存缓存/SQLite
- 第 1847 行："refresh Redis cache" → 应为刷新内存缓存

**影响**：V1.5 核心变更是脱离 MySQL/Redis，但附录时序图仍是旧版本，开发团队可能误用 MySQL/Redis。
**修改建议**：将 4 处引用全部替换为 SQLite 和内存缓存（TTLCache）。

#### P0-5：HLD 3.3.2 LLM 处理流程仍提到 MySQL

**位置**：HLD 第 463 行
**问题**：第 7 步"输出：稿件 + 分段 + 引用素材 URL，存入 MySQL script 表"
**影响**：V1.5 已改为 SQLite，但此处遗漏修改。
**修改建议**：改为"存入 SQLite script 表"。

#### P0-6：HLD 缺少云函数 SCF 详细设计章节

**位置**：HLD 第 2.2 节提到云函数 SCF，但第 3-6 章无专门章节
**问题**：
- 云函数是 V1.5 新增的核心组件，承载全部 C 端 API（5 个函数）
- HLD 中仅在 2.1/2.2/6.2/8.2 提及，无独立设计章节
- 缺少：云函数内部结构、部署配置、COS 读取逻辑、鉴权逻辑、冷启动处理、错误处理等

**影响**：开发团队无法独立完成云函数开发。
**修改建议**：新增"第 4.5 章 云函数 SCF 设计"或独立的"第 6.5 章"，包含：
1. 5 个函数的内部结构与代码组织
2. COS 对象读取约定（路径规范、JSON Schema）
3. 鉴权逻辑（JWT 签发/验签/黑名单）
4. 冷启动优化
5. 部署配置（SCF 控制台配置项、环境变量）
6. 错误处理与日志
